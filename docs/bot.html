SetnikBot

SetnikBot is the user agent of Setnik, a concert discovery app. It reads the public events page of music venues so their shows can be listed with a link back to the venue.

How it behaves

  • It obeys robots.txt, including Crawl-delay, and skips any page that disallows it.
  • It reads a venue's events page about once a week, waits at least 3 seconds between requests to the same host, and sends conditional requests (ETag, Last-Modified) so unchanged pages cost almost nothing.
  • It does not log in, solve CAPTCHAs, or try to get around a block. If a site blocks it, it stops and does not retry that site.
  • It takes show facts (artists, date, time, price, ticket link). Photos are linked to, not copied.

Ask us to stop

To exclude your site, add a rule for SetnikBot in robots.txt, or email setnik.app@gmail.com and we will remove your venue and its shows.
